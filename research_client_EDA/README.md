# research_client_EDA

## О проекте
EDA пользовательского поведения в мобильном банке на синтетических event-данных. Цель — понять паттерны активности, построить ключевую воронку и выявить сегменты с наибольшим потенциалом premium-конверсии.

## Цель приложения
- Определить, какие функции приложения наиболее вовлекающие.
- Найти узкое место в сценарии `view_banner -> click_banner -> sub_premium`.
- Сегментировать аудиторию по активности и оценить вклад сегментов в подписку premium.

## Стек
- Python
- pandas
- matplotlib
- seaborn

## Структура проекта
- `mobile_events.csv` — синтетические события пользователей за апрель 2025.
- `research_client_EDA.ipynb` — полный анализ по шагам: загрузка, метрики, события, воронка, retention, сегментация, выводы.

## Что сделано
- Проверка качества данных (пропуски, дубликаты, типы).
- Расчёт DAU/WAU/MAU и распределения активности пользователей.
- Частотный анализ событий и экранов.
- Построение воронки `баннер -> клик -> подписка` с конверсиями между этапами.
- Когортный retention-анализ по неделям.
- Сегментация пользователей по интенсивности активности и сравнение ключевых метрик.

## Ключевые инсайты (кратко)
- Наиболее частое и вовлекающее действие — `app_open`; в продуктовых сценариях выделяется `view_banner`.
- Основная потеря воронки происходит перед шагом подписки premium.
- Сегмент высокой активности показывает наибольшую долю premium.

## Как запустить
1. Открыть `research_client_EDA.ipynb`.
2. Выполнить ячейки сверху вниз.
3. Проверить графики и финальный блок с бизнес-рекомендациями.

## Что показать на собеседовании
- Логику event-EDA и выбор метрик.
- Интерпретацию воронки и retention-heatmap.
- Как сегментация переводится в продуктовые действия и гипотезы роста.
